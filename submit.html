📝 投稿須知
投稿送出後將先進入管理員審核流程，不會立即公開；是否發布由平台依規則審核決定。請勿投稿騷擾、威脅、違法內容或他人的私人資料。

🔒 匿名與隱私保護
公開貼文不會顯示投稿者的來源 IP 或身分資料。為防止濫用與維護平台安全，系統會利用來源 IP 產生投稿頻率限制識別值，並記錄成功投稿時取得的來源 IP。請不要在投稿內容中填入自己的真實姓名、聯絡方式或其他敏感資料。

🛡️ IP 紀錄保存
來源 IP 紀錄預設保存 30 天，並由後端排程定期清理；僅限授權人員在必要範圍內存取。

⚖️ 法律責任
匿名不代表免除法律責任。若涉及嚴重違法情事，平台得依法報案，並在符合法定要件及必要範圍內，配合警察或司法機關的合法調查程序。
